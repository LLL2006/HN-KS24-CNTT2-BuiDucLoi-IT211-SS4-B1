Client nhận về chuỗi
thay vì JSON vì trong phương thức getMovies() đang trả về:

return movies.toString();

movies là một List<Movie>. Khi gọi toString(), Java sẽ gọi toString() của từng đối tượng Movie.

Do class Movie chưa override toString(), Java dùng toString() mặc định của Object, nên kết quả có dạng:

TênClass@địa_chỉ_hash

Nguyên nhân gốc rễ: phương thức getMovies() trả về kiểu String và tự chuyển List<Movie> thành chuỗi, thay vì trả trực tiếp List<Movie> để Spring Boot tự động convert sang JSON.
